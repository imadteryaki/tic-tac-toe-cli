# Tic-Tac-Toe CLI

A two-player **Tic-Tac-Toe** game that runs in the terminal, written in **Node.js**.

```
        X   |  O   |  X
        ----+------+----
            |  X   |  O
        ----+------+----
        O   |      |  X
```

## Features

- Two players (X and O) take turns on the same terminal
- Choose a field by entering a position from 1 to 9
- Input validation (invalid or already taken positions)
- Win and draw detection
- Move counter and move history at the end of the game
- Coloured terminal output

## Getting Started

Requires Node.js.

```bash
npm install
node index.js
```

## Tech Stack

- Node.js (`readline`)
- `colors` for terminal styling
